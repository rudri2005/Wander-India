# 🇮🇳 Wander-India

**Discover India. Explore Beyond.**

Wander-India is a responsive travel website designed to showcase India's beautiful destinations, popular tourist attractions, cultural heritage, and travel experiences.

## 🌐 Live Website

[Visit Wander-India](https://wanderindia-eta.vercel.app/)

## ✨ Features

- Explore popular destinations across India.
- Discover famous tourist attractions.
- Travel gallery showcasing beautiful locations.
- Responsive and user-friendly interface.
- Destination images and travel inspiration.
- Easy navigation across website sections.

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript

## 📸 Website Preview

Explore the website to discover destinations, attractions, and travel inspiration from different parts of India.

## 🚀 Run Locally

1. Clone the repository:

   ```bash
   git clone https://github.com/rudri2005/Wander-India.git
   ```

2. Open the project folder in Visual Studio Code.
3. Open `index.html` using Live Server or your browser.
